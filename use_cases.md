# Casos de Uso - Amigo Oculto

Esta aplicação é uma plataforma para organizar e gerenciar sorteios de Amigo Oculto. Abaixo estão listados os casos de uso principais da aplicação:

## 1. Cadastro e Autenticação
- **Cadastrar Usuário**: O usuário pode criar uma nova conta fornecendo suas informações básicas.
- **Login**: O usuário cadastrado pode fazer login no sistema para acessar seus events.

## 2. Gerenciamento de Events (Administrador)
- **Criar Novo Event**: Um usuário autenticado pode criar um novo event de Amigo Oculto, definindo o nome do event, a data da troca de presentes e uma descrição.
- **Gerenciar Participantes**: O administrador do event pode visualizar a lista de participants que entraram no event.
- **Realizar o Sorteio**: O administrador do event pode acionar o sorteio. O sistema fará a distribuição aleatória de quem tirou quem, garantindo que ninguém tire a si mesmo.

## 3. Participação em Events
- **Entrar em um Event**: Um usuário pode entrar em um event (geralmente através de um convite ou link).
- **Gerenciar Lista de Desejos**: O participante pode adicionar, editar ou remover sugestões de presentes que gostaria de ganhar.
- **Visualizar Amigo Sorteado**: Após o sorteio ser realizado, o participante pode acessar o event e descobrir quem ele tirou.
- **Visualizar Desejos do Amigo**: O participante pode ver a lista de desejos da pessoa que ele tirou no sorteio para ajudar na escolha do presente.
